## Bienvenida

Este manual fue creado para acompañarle paso a paso en el uso del sistema **Expediente Clínico ZOE**, la herramienta digital que reemplaza los expedientes en papel del Hogar Zoé. Aquí encontrará instrucciones claras para cada función del sistema, escritas de manera sencilla y sin tecnicismos.

No es necesario leer todo el manual de una sola vez. Puede buscar el capítulo que necesita según la tarea que tenga en ese momento. Con el tiempo, el uso diario del sistema se volverá natural y fluido.

Si en algún momento tiene dudas que este manual no resuelve, comuníquese con el equipo de soporte técnico cuyos datos aparecen al final de esta página.

## Cómo usar este manual

- Cada capítulo cubre una sección del sistema de manera independiente. Puede leerlos en orden o ir directamente al capítulo que necesita.
- Los pasos están numerados. Siga cada paso en orden antes de pasar al siguiente.
- Las imágenes del sistema aparecen marcadas con `[CAPTURA]` en esta versión; en la versión impresa encontrará la pantalla correspondiente en ese lugar.
- Los cuadros de colores tienen significados especiales:

| Cuadro | Significado |
|---|---|
| **Importante** | Información que debe leer para evitar errores |
| **Nota** | Contexto adicional útil |
| **Consejo** | Buenas prácticas recomendadas |
| **Solo para administradores** | Función exclusiva del rol Administrador |
